# 部署教學：免費放一份到你自己的 GitHub

這份教學給**不會寫程式**的人。照著做，大約 10 分鐘，就會有一個你自己的網址，例如：

```
https://你的帳號.github.io/voice-task-reminder/
```

整個過程**免費**、**不用安裝任何軟體**，只要一個瀏覽器（Windows 用 Chrome 或 Edge 都可以）。

> 先認識兩個名詞
> - **GitHub**：放程式碼的網站，像程式版的 Google 雲端硬碟。
> - **Fork（分叉／複製一份）**：把別人公開的專案，完整複製一份到你自己的 GitHub 帳號底下。之後你可以自己管理，不會影響原作者。
> - **GitHub Pages**：GitHub 提供的免費網站空間，可以把專案直接變成一個網址。

---

## 第一步：註冊並登入 GitHub

1. 打開 <https://github.com/>。
2. 已有帳號：點右上角 **Sign in** 登入。
   沒有帳號：點 **Sign up**，依畫面輸入 Email、密碼、帳號名稱，完成 Email 驗證。
3. 記下你的**帳號名稱**（右上角大頭貼點開可以看到），之後網址會用到。

**成功的樣子**：右上角出現你的大頭貼。

---

## 第二步：Fork（複製）這個專案到你的帳號

1. 打開原始專案頁面：<https://github.com/ccchen0263-tech/voice-task-reminder>
2. 點右上方的 **Fork** 按鈕（旁邊有一個分岔的小圖示）。
3. 進入「Create a new fork」畫面：
   - **Owner**：選你自己的帳號。
   - **Repository name**：保持 `voice-task-reminder`（建議不要改，改了網址也會跟著變）。
   - **Copy the `main` branch only**：保持勾選。
4. 點綠色按鈕 **Create fork**。

**成功的樣子**：頁面左上角變成「你的帳號 / voice-task-reminder」，下方有一行小字「forked from ccchen0263-tech/voice-task-reminder」。

---

## 第三步：開啟 GitHub Pages（把專案變成網站）

1. 在**你自己的** voice-task-reminder 頁面，點上方的 **Settings**（齒輪圖示）。
   - 看不到 Settings？請確認左上角是你的帳號，不是原作者的。
2. 左邊選單往下找，點 **Pages**（在「Code and automation」分類底下）。
3. 在「Build and deployment」區塊：
   - **Source**：選 **Deploy from a branch**。
   - **Branch**：第一個下拉選 **main**，第二個下拉選 **/ (root)**。
4. 點 **Save**。

> 本專案是「靜態網頁」（只有 HTML、CSS、JavaScript 檔案，不需要伺服器運算），所以不需要任何建置設定，直接用 main 分支的根目錄就可以。

---

## 第四步：等網站上線（約 1～5 分鐘）

1. 等 1～2 分鐘後，重新整理 **Settings → Pages** 這一頁。
2. 頁面上方會出現：「**Your site is live at** `https://你的帳號.github.io/voice-task-reminder/`」。
3. 點旁邊的 **Visit site**。

想看進度：點專案上方的 **Actions** 分頁，會看到一個叫「pages build and deployment」的項目，出現綠色勾勾就代表完成；黃色圓圈代表還在跑。

**成功的樣子**：打開網址後看到「AI 語音待辦提醒系統」頁面，有輸入框和「語音輸入」按鈕。

---

## 第五步：實際試用一次

1. 在輸入框打：`明天早上八點提醒我買早餐`
2. 下方預覽應該顯示行程名稱「買早餐」，開始時間是明天 08:00。
3. 點 **開啟 Google Calendar**，會跳到 Google 日曆的新增畫面（沒登入 Google 會先要求登入）。
4. 確認內容後，在 Google 頁面按 **儲存**，行程才會真的加入。
5. 用手機測語音：用手機的 Chrome 打開你的網址 → 點「語音輸入」→ 第一次會問是否允許使用麥克風，請按「允許」。

想放到手機桌面：手機 Chrome 右上角「⋮」→「加到主畫面」；iPhone Safari 點「分享」→「加入主畫面」。

---

## 之後怎麼更新成新版本（Sync fork）

原作者更新程式後，你的複製版**不會自動更新**，要自己按一下：

1. 打開你自己的 voice-task-reminder 頁面（`https://github.com/你的帳號/voice-task-reminder`）。
2. 檔案列表上方會顯示「This branch is X commits behind ...」。
3. 點 **Sync fork** → 再點 **Update branch**。
4. 等 1～5 分鐘，GitHub Pages 會自動重新上線新版本。

如果畫面出現 **Discard commits**（捨棄修改）而不是 Update branch：代表你曾經自己改過檔案，跟新版有衝突。按下去會**刪掉你自己的修改**，換成原作者最新版。沒有自己改過程式的人，可以放心按。

更新後手機看到的還是舊版？把網頁關掉重開，或在瀏覽器重新整理。

## 常見問題與解法

| 狀況 | 可能原因 | 解法 |
| --- | --- | --- |
| 打開網址出現 **404 File not found** | 剛開啟 Pages，還沒部署完 | 等 5 分鐘再重新整理；到 **Actions** 分頁看是否有綠色勾勾 |
| 一直 404 | 網址打錯，或 Pages 設定沒存 | 網址結尾要有 `/voice-task-reminder/`，大小寫要一致；回 **Settings → Pages** 確認 Branch 是 `main`、`/ (root)` 並按過 Save |
| Actions 分頁顯示「Workflows aren't being run on this forked repository」 | GitHub 對 fork 專案預設暫停自動流程（不確定是否影響 Pages，依 GitHub 當時設定而定） | 點 **I understand my workflows, go ahead and enable them**，再回 Settings → Pages 按一次 Save |
| Settings 裡沒有 Pages | 你在原作者的專案頁，不是自己的 | 確認左上角是你的帳號 |
| Pages 說私人專案不能用 | 免費方案的 GitHub Pages 只支援公開專案 | Fork 出來的專案保持 **Public**（公開） |
| 網頁畫面亂掉、沒有顏色 | 瀏覽器快取到舊檔案 | 按 `Ctrl` + `F5` 強制重新整理 |
| 「語音輸入」按鈕是灰色，顯示「此瀏覽器不支援語音輸入」 | 瀏覽器沒有語音辨識功能 | 改用電腦或 Android 的 **Chrome／Edge**；iPhone 支援度依 iOS 版本而定（不確定），可改用手機鍵盤上的麥克風聽寫，或直接打字 |
| 顯示「語音輸入需要安全連線」 | 網址不是 `https://` 開頭 | 使用 GitHub Pages 給的 `https://` 網址 |
| 顯示「無法使用麥克風」 | 之前按了「封鎖」 | 點網址列左邊的圖示 →「網站設定」→ 麥克風改成「允許」，再重新整理 |
| 顯示「語音辨識服務無法連線」 | 瀏覽器的語音服務需要網路 | 確認網路正常，或改用打字 |
| 時間差了好幾個小時 | 手機或電腦的時區設定不對 | 到裝置的「日期與時間」設定，開啟自動時區 |
| 到 Google 後沒有帶入「重複」 | Google 沒有正式支援這個連結參數（不確定） | 在 Google 的新增畫面手動設定重複，描述欄裡會寫著你選的重複方式 |
| 按了儲存但手機沒提醒 | 提醒是 Google 日曆發的 | 檢查 Google 日曆 App 的通知權限與該行程的「通知」設定 |

## 另一個選擇：Cloudflare Pages（簡要）

如果你已經在用 Cloudflare，也可以免費放在 Cloudflare Pages（介面名稱可能會改，以下按鈕名稱不確定）：

1. 先完成上面的「第二步：Fork」。
2. 登入 <https://dash.cloudflare.com/> → **Workers & Pages** → **Create** → 選 **Pages** → **Connect to Git**，授權並選擇你 fork 的 `voice-task-reminder`。
3. 設定：Framework preset 選 **None**；Build command 填 `npm run build`；Build output directory 填 `dist`。
4. 按 **Save and Deploy**，完成後會得到一個 `https://xxxx.pages.dev` 網址。

之後在 GitHub 按 Sync fork 更新，Cloudflare 也會自動重新部署。

---

## 需要改任何設定嗎？

**不需要。** 這個網頁沒有密碼、金鑰或帳號設定，複製下來就能直接用。

想改網頁標題（例如改成「我的行程小幫手」）：在你的 GitHub 專案點 `index.html` → 右上角鉛筆圖示（Edit）→ 修改 `<title>` 和 `<h1>` 那兩行的文字 → 右上角 **Commit changes**。幾分鐘後網站會自動更新。（注意：改過檔案之後，日後 Sync fork 可能會出現 Discard commits，見上面說明。）
