# 語音行事曆小幫手（voice-task-reminder）

用說的或用打的，把「明天早上八點提醒我買早餐」變成一筆 **Google 日曆（Google Calendar）** 行程草稿。確認後按一下，就會打開 Google 日曆的新增畫面，你在 Google 按「儲存」才會真的加入。

- 不用登入本網頁、不用申請任何金鑰（API Key，一種讓程式連到服務的密碼）
- 不需要資料庫、不需要伺服器，免費放在 GitHub Pages 就能用
- 手機優先設計，電腦也能用

→ **想放一份到自己的空間使用？請看 [部署教學](docs/部署教學.md)**（不用寫程式，約 10 分鐘）。

→ **使用方式與常見問題：[使用說明](使用說明.md)**

## 功能

- **語音輸入**：點「語音輸入」後說話，最長 120 秒，可隨時再點一次停止。
- **自動抓時間**（用規則判斷，不是 AI）：
  - 相對時間：「十分鐘後」「半小時後」「一個半小時後」「等一下」「晚一點」
  - 日期：「今天」「明天」「明早」「明晚」「後天」「這週五」「下週一」
  - 星期與日期：「星期五」「禮拜五」「週五」「15號」「12月1日」（自動取下一個還沒過的那天）
  - 鐘點：「下午三點半」「晚上十點」「8:30」
  - 重複：「每天」「每週一」「每月5號」「每年」「平日」（會自動選好「希望重複」）
- **時間已過會處理**：沒說日期而時間已經過了，會自動改成今天稍後或明天；若你明確說「今天早上八點」「這週一」但已經過去，畫面會顯示黃色警告，讓你在送出前修正。
- **送到 Google 前可修改**：行程名稱、開始時間、地點、備註、重複方式。
- 深色／淺色主題切換。

## 限制（請先了解）

- **提醒通知是由 Google 日曆發出的，不是這個網頁。** 本網頁只負責幫你填好草稿；要在 Google 頁面按「儲存」後，Google 才會依你的日曆設定通知你。
- 本網頁無法得知你是否已在 Google 按下儲存。
- 重複設定會嘗試透過連結直接帶入 Google（`recur` 參數）。這個做法網路上很多人使用，但 **Google 官方文件沒有正式列出（不確定未來是否一直有效）**，所以同時把「希望重複」寫在行程描述裡，儲存前請在 Google 畫面確認。
- 語音輸入要用 **HTTPS 網址**（網址開頭是 `https://`，GitHub Pages 預設就是）以及支援的瀏覽器：電腦或 Android 的 Chrome、Edge 可用；iPhone／iPad 的支援程度依 iOS 版本而定（不確定），不行時可以改用手機鍵盤上的麥克風聽寫，或直接打字。
- 時間解析是固定規則，說法太口語或太複雜可能抓不到，請看預覽確認。

## 隱私

- 本網頁**不會把你的內容存到任何伺服器**，也不使用瀏覽器的本機儲存。輸入的文字只暫留在目前分頁，重新整理就會消失。
- 只有在你按「開啟 Google Calendar」時，行程名稱、時間、地點、備註會放在連結中交給 Google。
- 語音辨識由瀏覽器提供；以 Chrome 為例，聲音可能會送到瀏覽器廠商的語音服務辨識（依瀏覽器而定）。

## 專案結構（給想改程式的人）

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`styles.css` | 網頁畫面 |
| `js/google-app.js` | 畫面操作的主程式 |
| `js/time-parser.js` | 把中文句子轉成日期時間 |
| `js/google-calendar.js` | 產生 Google 日曆預填連結 |
| `js/speech-input.js` | 語音輸入 |
| `js/planner.js` | 日期格式轉換小工具 |
| `server.js` | 本機預覽用的小伺服器（只在自己電腦測試時用） |
| `tests/` | 自動測試 |

本機預覽與測試需要先安裝 [Node.js](https://nodejs.org/)（22 版以上）：

```powershell
npm start          # 只有這台電腦能開：http://localhost:5173/
npm run dev:lan    # 讓同一個 Wi-Fi 的手機也能開（只能測畫面，手機語音需要 HTTPS）
npm test           # 跑自動測試
npm run test:tz    # 在台北、UTC、美國等多個時區各跑一次測試
npm run build      # （選用）把網頁需要的檔案複製到 dist 資料夾
```

不需要 `npm install`，沒有任何外部套件。
